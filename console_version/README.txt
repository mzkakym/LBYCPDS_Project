Original console prototype of the borrowing feature (kept for reference).
These files are NOT part of the Maven build. The JavaFX version lives in:
  models/Equipment.java, models/BorrowRequest.java, utils/Data_Store.java,
  controllers/Borrower_controller.java, resources/fxmls/borrower/Borrower_View.fxml
To run the console version, copy these 4 files into an empty plain Java project.
